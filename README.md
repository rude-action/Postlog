# PostLog — ポストアーカイブビューア

X(Twitter)のアーカイブデータ(`tweets.js`)を最初から同梱した、ポスト閲覧ビューアです。
ページを開くだけで自動的にアーカイブが読み込まれ、フィードが表示されます。

単一HTML・依存ゼロ・ビルド不要で、Vercelなどの静的ホスティングにそのままデプロイできます。

## 機能

- **自動読み込み** — ページ表示時に同梱の `tweets.js` を取得して解析します(ファイル選択やドロップは不要)
- **検索** — 本文・ユーザー名・スクリーンネームでの部分一致検索
- **フィルタ** — すべて / 返信 / リポスト / メディア / 長文 の絞り込み(件数付きチップ)
- **並べ替え** — 新しい順 / 古い順 / いいね順 / リポスト順
- **リッチ表示** — リポスト元・返信先の注記、引用ポスト、画像・動画、Reply/RT/いいね/引用数
- **ページング** — 50件ずつの段階表示(全件を一度にレンダリングしません)
- ハッシュタグ・メンションクリックでその場で検索

## 対応データ形式

`tweets.js` は次のいずれの形式でも解析できます:

1. YTD形式: `window.YTD.tweets.part0 = [{"tweet":{...}}, ...]` (X公式アーカイブ / x-posts-exporter)
2. `[{"tweet":{...}}]` のみのJSON配列
3. x-posts-exporter の正規化JSON(レコード配列)

## ファイル構成

```
archive-viewer/
├── index.html   # ビューア本体(HTML + CSS + JS、依存ライブラリなし)
├── tweets.js    # アーカイブデータ(同梱済み)
└── README.md
```

## ローカルで動かす

`fetch` を使うため、ファイルを直接開くのではなくローカルサーバー経由で確認してください。

```bash
cd archive-viewer
npx serve .
# または
python -m http.server 8000
```

`http://localhost:3000`(serve)または `http://localhost:8000`(python)をブラウザで開きます。

## Vercelにデプロイする

静的ファイルのみなので、ビルド設定は一切不要です。

### CLIの場合

```bash
cd archive-viewer
npx vercel --prod
```

初回のみログインとプロジェクト名を聞かれます。
Framework Preset は **Other**、Build Command / Output Directory は**空欄**のままでOKです。

### GitHub経由の場合

1. このフォルダをリポジトリとしてpush
2. Vercelで「Add New Project」からインポート
3. 設定を変更せずに Deploy

## アーカイブを更新する

新しいアーカイブを取得したら、`tweets.js` を同じファイル名で差し替えて再デプロイするだけです。
重複はIDで自動統合されるため、複数アーカイブを連結したファイルを置いても問題ありません。

## 注意事項

- **画像・動画はリモート参照** — メディアは `pbs.twimg.com` などのURLを直接参照するため、表示にはネット接続が必要です(アーカイブに画像実体は含まれません)
- **公開範囲** — デプロイするとアーカイブ全体(ポスト本文・メディアURLなど)が公開URLで誰でも閲覧できる状態になります。非公開にしたい場合は Vercel の Protection を有効化してください
- 独自UIであり、X(Twitter)の配色・アイコン・フォントは使用していません
